# 🎄 AI Advent Challenge - Day 19: RAG Chatbot with Memory

В рамках **Day 19** мы объединили возможности RAG (поиск по документам) и долгосрочную память (история диалога с суммаризацией) в единое консольное приложение.

## 🚀 Функционал

1.  **RAG (Retrieval-Augmented Generation):**
    *   Поиск релевантных фрагментов в локальных `.md`/`.txt` файлах.
    *   Использование **Yandex Cloud Embeddings** для векторизации.
    *   Фильтрация результатов по порогу сходства (Cosine Similarity).
    *   Красивый вывод источников со сниппетами.

2.  **Умная память (Memory):**
    *   Сохранение истории диалога между перезапусками (`chat_history.json`).
    *   **Суммаризация:** При превышении лимита сообщений (6 шт.) старая часть диалога сжимается LLM в краткое саммари, сохраняя контекст без переполнения токенов.

3.  **Интерактивный CLI:**
    *   Режим `chat` для общения.
    *   Команды управления (`/clear`, `/exit`).
    *   Цветной вывод и индикация релевантности источников.

## 🛠 Установка и Запуск

1.  **Предварительные требования:**
    *   JDK 17+
    *   Yandex Cloud API Key & Folder ID

2.  **Конфигурация:**
    Создайте файл `local.properties` в корне проекта:
    ```properties
    yandex.api.key=AQVN...
    yandex.folder.id=b1g...
    ```

3.  **Подготовка данных:**
    Создайте папку `documents/` в корне проекта и положите туда текстовые файлы (`.md`, `.txt`), по которым бот будет искать ответы.

4.  **Запуск:**
    ```bash
    ./gradlew run
    ```

## 🎮 Использование

После запуска вы попадете в главное меню.

### 1. Создание индекса (первый запуск)
Перед началом общения нужно проиндексировать документы:
```text
> index documents
```
Это создаст файл index.json с векторами.

### 2. Запуск чата

```text
> chat
```
Вы попадете в режим диалога:

```text
🤖 KOTLIN RAG CHAT :: DAY 19 CHALLENGE
...
User 👤 > Что такое RAG?
Bot 🤖 > RAG — это ... [ответ]

┌── 📚 Источники контекста ────────┐
│ 1. lecture.md (0.85)
│    "RAG combines retrieval..."
└──────────────────────────────────┘
```
Команды внутри чата:

**/clear** — очистить память (забыть контекст и саммари).

**/exit** — вернуться в главное меню.

### 3. 🔬 Другие команды меню

| Команда               | Описание                                                                         |
|-----------------------| -------------------------------------------------------------------------------- |
| ```search <запрос>``` | Тестовый поиск по базе (показывает найденные куски текста без генерации ответа). |
| ```compare```         | Запуск сравнения качества ответов "с RAG" и "без RAG" (из Day 17).               |
| ```stats```           | Показать количество чанков в текущем индексе.                                    |
| ```exit```            | Выйти из программы.                                                              |

## 📂 Структура проекта

*   `src/main/kotlin/.../rag/`
    *   📂 **services/**
        *   `ChatService.kt` — 🧠 Мозг чата: управление RAG, промптами и сжатием истории.
        *   `IndexService.kt` — Работа с векторным индексом.
        *   `SearchService.kt` — Математика поиска (Cosine Similarity).
    *   📂 **models/**
        *   `ChatHistory.kt` — Модель истории с полем `summary`.
    *   📂 **repository/**
        *   `HistoryRepository.kt` — Сохранение JSON.
    *   `Main.kt` — Точка входа и CLI UI.
