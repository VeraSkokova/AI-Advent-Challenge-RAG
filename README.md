# 🎄 AI Advent Challenge — Day 16: RAG System

**Проект:** Консольная система RAG (Retrieval Augmented Generation) на Kotlin.  
**Задача:** Реализовать индексацию документов, разбиение на чанки (chunking) и семантический поиск с использованием Yandex Cloud Embeddings API.

---

## 🛠 Технологический стек

Проект реализован на актуальном стеке технологий (согласно требованиям Day 15/Day 10):

*   **Язык:** Kotlin 2.2.20 (JVM)
*   **Сетевой клиент:** Ktor Client 3.0.0 (CIO engine)
*   **Асинхронность:** Kotlin Coroutines 1.9.0
*   **Сериализация:** Kotlinx Serialization 1.6.0
*   **AI API:** Yandex Foundation Models (Embeddings)

## 🚀 Основные возможности

1.  **Умный Чанкинг (Smart Chunking)**
    *   Реализован алгоритм `Sentence-aware Sliding Window`.
    *   Текст разбивается не просто по символам, а по границам предложений.
    *   **Размер окна:** 512 символов.
    *   **Перекрытие (Overlap):** 100 символов (для сохранения контекста на стыках).

2.  **Векторизация (Embeddings)**
    *   Используются модели Яндекса:
        *   `text-search-doc` — для документов.
        *   `text-search-query` — для поисковых запросов.
    *   Реализован **Retry-механизм** (экспоненциальная задержка) для обработки ошибок API (Rate Limits).

3.  **Семантический поиск**
    *   Вычисление косинусного сходства (Cosine Similarity) между вектором запроса и векторами чанков.
    *   Ранжирование результатов по релевантности.

4.  **Персистентность**
    *   Индекс сохраняется на диск в формате JSON (`index.json`).
    *   Поддерживается загрузка существующего индекса при старте.
