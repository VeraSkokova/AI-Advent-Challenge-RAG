## Вопрос 4: "В чём разница между text-search-doc и text-search-query моделями?"

### ✅ Ответ С RAG

**Использованные чанки:**

1. **[project_day17_info.md]** (Score: 0,5049)
   > “**text-search-query** — для поисковых запросов  - URI:...”

2. **[project_day17_info.md]** (Score: 0,4775)
   > “**Особенности:** - Текст разбивается **по границам предложений**, а не просто по символам -...”

3. **[rag_llm_source_clean.txt]** (Score: 0,4569)
   > “Во‑первых, это контекст. У LLM есть ширина контекста, контекстное окно, в которое могут поместиться...”

**Ответ модели:**

**text-search-doc** используется для векторизации документов при индексации чанков, а **text-search-query** — для преобразования поисковых запросов в вектор [источник: project_day17_info.md].

### ❌ Ответ БЕЗ RAG

**Text-search-doc** и **text-search-query** — это два разных типа моделей, используемых в системах поиска информации. Они применяются для разных целей и обрабатывают разные типы данных.

**Text-search-doc модели** предназначены для обработки и индексации текстовых документов. Они анализируют содержание документов, извлекают ключевые слова и фразы, а также создают индексы для быстрого поиска. Эти модели помогают системе понимать структуру и содержание документов, чтобы впоследствии можно было эффективно выполнять поиск по ним.

**Text-search-query модели**, напротив, фокусируются на обработке поисковых запросов. Они анализируют запросы пользователей, определяют их намерения и ключевые слова, а затем используют эту информацию для поиска соответствующих документов. Эти модели помогают системе понимать, что именно ищет пользователь, и предоставлять наиболее релевантные результаты.

Таким образом, основное различие между этими двумя типами моделей заключается в том, что **text-search-doc** модели работают с документами, а **text-search-query** модели — с поисковыми запросами. Вместе они обеспечивают эффективный и точный поиск информации в больших объёмах текстовых данных.
